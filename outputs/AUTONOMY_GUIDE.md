# Автономный запуск

В этой версии используется автоматизация по правилам, без платного OpenAI API.

## На Mac / Windows

1. Откройте приложение. Выберите платформу → «Настроить вход».
2. Войдите в открывшемся браузере и закройте его окно. Пароли/OTP вводятся только
   на сайте. Программа сохраняет выделенный профиль, не читая ваши cookies.
3. Настройте поиск. Telegram: категория `tech` или конкретные каналы. WB/Ozon/
   Twitch/Kick: можно оставить ссылки пустыми для выбора карточек из каталога.
   Instagram/YouTube: пока нужны прямые ссылки на профили.
4. Проверьте результат кнопкой «Запустить сейчас», сначала без записи.
5. Укажите интервал и нажмите «Сохранить в расписание». Первый запуск начнётся
   автоматически. Для записи нужна отдельная включённая галочка.

Пока окно открыто, расписание работает. После закрытия задания сохраняются,
но выполняться не могут. Перезапуск приложения подхватит расписание. При сбое
незавершённые задания отключаются до проверки журналов и ручного возобновления.
Запрос авторизации или ошибка источника приостанавливает это задание; другие
сохранённые задания продолжаются. Один источник с неясной записью не повторяется.

Сессия может истечь. Тогда снова используйте «Настроить вход», проверьте сбор,
затем возобновите задание. Первый вход и обязательные проверки платформы
не автоматизированы. Сохранённый профиль ещё не доказывает успешный вход.

## Постоянно включённый Linux-сервер

Нужна начальная настройка администратором. Без доступа к серверу вообще нельзя
настроить аккаунты или восстановить их при обязательной проверке входа.

1. Установите Python 3.11+, проект и зависимости requirements.txt в /opt/adresearch.
2. Создайте /opt/adresearch/.venv и установите Chromium Playwright для Linux в
   /opt/adresearch/cache/ms-playwright (системные зависимости нужны отдельно).
3. Создайте задания в панели на сервере через SSH-туннель; сервер слушает только
   127.0.0.1. Не публикуйте порт панели в интернет.
4. При необходимости входа запустите `python -m agent --setup-session tgstat`
   в графической сессии сервера под тем же пользователем. Для других платформ
   допустимы wb, ozon, instagram, youtube, twitch, kick. После входа закройте окно.
   Для сервера без графики нужен временный защищённый удалённый рабочий стол.
   Профили с Mac не считаются переносимыми и проверенными для Linux.
5. Закройте панель и запустите `python -m agent --service` для проверки.
6. Администратор адаптирует adresearch.service, устанавливает unit в systemd,
   включает и запускает сервис. В unit должны совпадать пользователь и пути.

Не копируйте .venv между ОС. Не выкладывайте .env, cache/browser_profiles,
таблицы или резервные копии в публичный репозиторий. Используйте отдельного
пользователя ОС с доступом только к проекту и его данным.

Сервис восстанавливает расписание после рестарта. Незавершённые операции
записи требуют проверки changes_log.csv и backups. Это сознательная защита
данных: неограниченных автоматических повторов после неизвестного результата нет.

## Где данные

Исходники: data/, backups/, logs/, cache/ внутри проекта.
Сборка Mac: ~/Library/Application Support/AdResearchAgent.
Сборка Windows: %LOCALAPPDATA%/AdResearchAgent.
Папки разные. Автоматического переноса существующих таблиц или аккаунтов нет.

Программа не отправляет сообщения рекламодателям. Неподтверждённые факты и
контакты сохраняются в отчётах для проверки. Полноценный автоматический поиск
и подтверждение всех рекламодателей пока не реализованы; правила качества
не ослабляются ради количества.
