# Настольное приложение: Mac и Windows

## Mac Apple Silicon — готовая сборка

Откройте папку desktop-darwin-arm64 и запустите **AdResearchAgent.app**.
Это отдельное системное окно, без вкладки браузера и ручного запуска сервера.
Приложение уже запускалось и проверялось на текущем Mac.

Рядом с .app находится **browser_engine**. Храните их вместе. При переносе
на другой Mac переносите всю папку из архива, не только .app.
Сборка предназначена для Apple Silicon. Для Intel нужен отдельный билд.

## Windows — готовая сборка и исходники

Windows x64 собирается на GitHub Actions под Windows. Автотесты и проверка
упакованного процесса агента пройдены. Ссылка на последний успешный артефакт
есть в outputs/WINDOWS_DOWNLOAD.md. Скачайте ZIP и распакуйте всю папку.
Запускайте AdResearchAgent.exe. Графическое окно на физическом Windows-ПК
ещё требует пользовательской проверки.

Альтернатива: архив **Agent-Windows-source.zip** содержит исходники и команды установки.

1. Установите Python 3.11+ с python.org.
2. Распакуйте архив в отдельную папку.
3. Запустите **Установить приложение Windows.bat**. Нужен интернет.
4. Затем запускайте **Запустить приложение.bat** — откроется собственное окно.
5. Чтобы получить папку с .exe, выполните **Собрать Windows.bat**.

Результат сборки: outputs/desktop-windows-*/AdResearchAgent/AdResearchAgent.exe.
Передавайте всю папку AdResearchAgent вместе с библиотеками и browser_engine.
Один файл exe отдельно не работает. На некоторых системах нужен Microsoft
WebView2 Runtime. Сборка и фоновый процесс проверены в Windows CI; окно требует проверки на вашем ПК.

## Данные и аккаунты

Упакованное приложение использует собственную папку данных:
- Mac: ~/Library/Application Support/AdResearchAgent;
- Windows: %LOCALAPPDATA%/AdResearchAgent.

При запуске из исходников данные остаются в папке проекта. Старые таблицы,
.env и авторизованные профили автоматически не импортируются в сборку.
Они не включены в архивы. Существующая база проекта не изменена.
Проверяйте, с какой папкой данных работаете, прежде чем разрешать запись.

Автономные сборщики используют сохранённые сессии. Для первого входа есть
кнопка «Войти в аккаунт»: войдите на сайте и закройте отдельное окно браузера.
Приложение не обходит блокировки и не восстанавливает автоматически все входы.
По умолчанию запись отключена. Ручные поля защищены прежним safe_writer.

## Расписание и сервер

В приложении можно сохранять задания с интервалом 5 минут–7 суток, ставить их
на паузу и читать последний отчёт. Задания сохраняются после перезапуска.
Закрытое приложение не выполняет расписание; серверный режим —
`python -m agent --service`. Подробности: AUTONOMY_GUIDE.md.
В текущей версии нет платного LLM API — решения принимаются по правилам.
Ошибки доступа и неизвестный результат записи не повторяются автоматически.
В реальной проверке расписание запустило TGStat, получило HTTP 403 и отключило
соответствующее задание; после перезапуска оно осталось на проверке.
Это подтверждает восстановление и управление, не успешный сбор TGStat.

## Обновлённое управление

На главном экране выберите **Задачу** (каналы, рекламодатели или стримеры),
затем платформу и нажмите **Пуск**. **Стоп** останавливает текущий процесс.
Для Telegram тематика выбирается по русскому названию; «Другая категория»
позволяет указать код TGStat. Конкретные ссылки, запись и расписание доступны
в «Дополнительных настройках». Конкретные каналы имеют приоритет над тематикой.

Ошибка источника теперь видна на главном экране, а исходное сообщение — в
диагностике. HTTP 403 означает отказ сайта в доступе: изменение интерфейса его
не устраняет. Обычный браузер может открывать сайт, когда фоновый сбор блокируется.
Не повторяйте запросы бесконечно; успешный сбор после входа пока не подтверждён.

Исправлено распознавание закрытия окна настройки сессии. Закрытие вкладки перед
событием закрытия контекста теперь не считается ошибкой входа. Сам факт закрытия
окна не подтверждает авторизацию — она проверяется при последующем сборе.

## Версия от 20 октября 2026

Для Mac используйте Agent-macOS-AppleSilicon-Latest.zip. Распакуйте весь архив;
AdResearchAgent.app и browser_engine оставьте рядом. Запустите приложение.
Рабочий сценарий без аккаунта: «Найти Telegram-каналы» → «Telegram · публичный
поиск кандидатов» → фраза от 3 символов → «Пуск». Для проверки конкретного
канала раскройте дополнительные настройки и введите @kod_ru. Конкретные каналы
имеют приоритет над поисковой фразой.

Карточки показывают найденные факты, причины проверки и рекламный контакт,
если он явно указан в описании. «Открыть источник» открывает публичную страницу.
В «Подробном отчёте» доступно скачивание JSON. Для публичного поиска запись в
рабочие таблицы отключена: география и средний охват ещё требуют подтверждения.
Результат review не означает подходящую рекламную площадку.

Локально проходят 192 теста; реальный поиск проверен в упакованном процессе Mac.
Графические элементы этой версии вручную пока не проверены. Другие браузерные
источники не подтверждены реальными успешными запусками в текущей среде: запуск
Chromium здесь ограничен системой. Автовосстановление входов не реализовано.
Новая сборка не переносит аккаунты, пароли или таблицы с компьютера разработчика.

## Функции от 24 октября 2026

Последний отчёт поиска возвращается после перезапуска. Ранее выданное разрешение
на запись не возвращается: перед ручной записью снова запросите план.

Раздел «Мои таблицы» позволяет посмотреть рекламодателей, Telegram и стримеров,
затем скачать CSV. В окне показаны первые 100 строк; экспорт включает все строки
(просмотр до 2 МБ). Данные при этом не редактируются.

Для рекламодателей дополнительные настройки содержат загрузку JSON-файла фактов
до 12 КБ. Отметьте подтверждение личной проверки файла. В каждом факте должны быть
value, url, checked_at с часовым поясом и operator_verified=true. Ключи файла —
нормализованные прямые ссылки карточек соответствующей платформы. Формат совпадает
с --brand-proofs; пароли и ключи API не загружаются. Для расписания эти факты
сохраняются, но после истечения их свежести потребуется обновление.

Опция проверки официального сайта использует уже подтверждённый адрес. При отказе
сайта кандидат остаётся на проверке. Найденные контакты не записываются в ручные
поля. По одному названию официальный сайт автоматически ещё не определяется.


### Google Sheets

В панели есть раздел «Подключить Google Sheets»: добавьте JSON-ключ служебного
аккаунта локально, предоставьте этому аккаунту доступ редактора к таблице и
вставьте ссылку на лист. Приложение покажет, какое поле в какую колонку попадёт.
Заголовки должны точно соответствовать одному из трёх согласованных типов.
Облачная запись добавляет только новые строки; существующие остаются нетронутыми.
Сначала используйте предпросмотр. Ключи не входят в установочный архив.
