# Состояние проекта — 18 октября 2026

Готова версия для проверки автономного запуска по правилам. Полностью завершённым
весь исходный проект пока не является: успешный живой сбор всех источников и
автономное подтверждение рекламодателей не проверены.

| Возможность | Состояние |
|---|---|
| Три фиксированные таблицы, валидация, дедупликация | Реализованы, тесты проходят |
| Защита ручных и заполненных полей, журнал, бэкапы | Сохранены, тесты проходят |
| Приложение Mac и Windows | Сборки готовы; Mac окно проверено, Windows процесс проверен в CI |
| Расписание и сохранение заданий | Реализованы: последовательное выполнение, lease, пауза, восстановление |
| Серверный запуск без UI | Реализован --service; шаблон systemd подготовлен, на сервер не установлен |
| Вход в аккаунты | Окно первой авторизации и сохранение сессий для семи платформ; проверка доступа при сборе |
| Восстановление OTP/CAPTCHA/просроченного входа | Требует владельца аккаунта |
| Telegram TGStat | Сборщик есть; свежая проверка сборки получила HTTP 403 и корректно остановилась |
| WB/Ozon/Twitch/Kick | Сбор видимых страниц и первый набор карточек каталога; сквозной живой запуск не подтверждён |
| Instagram/YouTube | Сбор по исходным ссылкам; универсальный поиск ещё не реализован |
| Проверка качества рекламодателей | Строгие правила и скоринг есть; без достаточных проверенных фактов — review |
| Контакты | Предложения; автоматическое подтверждение и рассылка отсутствуют |
| Платный LLM API | Не используется по выбранному режиму |
| Отдельное удалённое управление сервером | Пока не реализовано; панель доступна только локально/через SSH-туннель |

На этом этапе изменены agent.py, control_panel.py, wb_parser.py, два файла тестов
и документация. Добавлены инструкции и шаблон сервиса внутри outputs/.
Изменений в рабочих таблицах, .env, config.py, safe_writer.py и базовых
requirements.txt на этом этапе нет. Ранее добавленные desktop.py и сборщик
использованы для обновления пакетов. Удалений исходных файлов нет.

Следующая необходимая проверка: настроить действующие аккаунты кнопкой
«Войти в аккаунт», запустить каждый источник в режиме просмотра и проверить
подтверждённые факты. Доступа к вашему серверу нет; развёртывание ещё не выполнено.
Для продолжения полного поиска брендов нужно дополнить enrichment и проверку
принадлежности сайта/контакта/географии без ослабления фильтров качества.


Обновление управления: главный экран «Задача → Платформа → Пуск», явный Стоп,
дополнительные настройки свёрнуты. Исправлены случайный запуск через Enter и
распознавание закрытия окна входа. 172 теста проходят локально. Повторный TGStat
в фоновом режиме по-прежнему получает HTTP 403, включая каталог /tech.
Успешный поиск после входа не подтверждён; интерфейс показывает причину сразу.

В шаге упрощения управления изменены control_panel.py, wb_parser.py
(закрытие окна входа), tests/test_control_panel.py, tests/test_sources.py
и документация. agent.py, config.py, safe_writer.py, схемы таблиц, .env
и рабочие таблицы не менялись. Проверено 172 теста локально, включая реальный
JavaScript-сценарий явного запуска кнопкой; выбор задачи также проверен в Mac .app.
